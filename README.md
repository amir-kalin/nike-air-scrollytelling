# Nike Air Jordan IV // "Sail" — React Scrollytelling Experience

A high-precision, interactive Apple & Nike-inspired 3D scrollytelling web experience built with **React**, **GSAP ScrollTrigger**, **Lenis Smooth Scroll**, and **HTML5 Canvas 2D Frame-Scrubbing Engine**.

## ✨ Features
- **241 Preloaded High-Definition Frames**: Seamless, hardware-accelerated 360° product rotation and scrollytelling.
- **Lenis Smooth Scrolling**: Ultra-fluid momentum scrolling with cubic-bezier inertial dampening.
- **GSAP ScrollTrigger Synchronization**: Millimeter-precision timeline scrubbing across 4 architectural story milestones.
- **Retina & High-DPI Canvas Rendering**: Aspect ratio containment with sub-pixel interpolation and zero distortion.
- **Interactive 360° Scrubber Slider**: Manual rotational timeline controller to examine the sneaker from any perspective.
- **Dual Visual Modes**: Studio Light (exact backdrop match) and Stealth Dark modes.
- **Web Audio Engine**: Procedural micro-interaction feedback (swoosh and clicks).
- **Responsive & Mobile Ready**: Clean glassmorphism UI optimized for touch screens and desktop displays.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Motion & Physics**: GSAP 3 + ScrollTrigger + Lenis
- **Rendering**: Canvas 2D API (High-DPI optimized)
- **Icons**: Lucide React
- **Styling**: Modern CSS with Glassmorphism & Custom Variable Design Tokens

## 🚀 Getting Started
```bash
# Clone the repository
git clone https://github.com/amir-kalin/nike-air-scrollytelling.git

# Install dependencies
npm install

# Start local dev server
npm run dev
```
